# 自然语言参数用例（P 系列）— 供 `ask do "<任务>"` / `ask ask "<问题>"` 直接执行
#
# 与参数族 YAML 用例（s3/s4/m3/m4/c3/c4）一一对应：同一套功能点与参数面，自然语言形态。
# 分级同 YAML：简单 3-5 页、中等 5-10 页、复杂 10-20 页。
# do 任务由 agent 自主决策完成；ask 为只读问答（不点击）。

## NLP-1 简单（对应 S3-引擎直执行参数巡礼）

```bash
ask do "启动稀土掘金，进热榜：先向下滚半屏、再滚一整屏、然后一直滚到列表底部边界，接着回到顶部、再向下滚一屏就停；等2秒后按返回键回首页，确认首页搜索框可见、前台包名还是 com.daimajia.gold，最后做一次崩溃检查。"
```

## NLP-2 简单（对应 S4-感知与读取参数巡礼）

```bash
ask do "启动稀土掘金后做一轮感知检查：截图报告前台包名与分辨率；用可点过滤和全量两种 UI 树统计元素个数；定位「热榜」报告 bounds 和命中策略；然后进热榜，用 text= 与 index= 两种 selector 各读一次文本，做一次画面树哈希对比，等一次画面稳定（超时8秒），把 UI 树落盘取证；最后提取热榜前3名标题存为数据集 s4_hot_top，按返回键回首页。"
```

## NLP-3 中等（对应 M3-输入与动作参数巡礼）

```bash
ask do "在掘金里搜两次：第一次搜 Android，把结果条目的标题和作者提取存成数据集 m3_results；长按结果里含 Android 字样的第一条约0.8秒，有弹层就关掉；用区域滑动（从底部滑到顶部、时长500毫秒）滑一次列表。回首页后第二次搜「安卓开发」，确认结果出来后，用 data_query 从 m3_results 取前3条标题看看。"
```

## NLP-4 中等（对应 M4-网络与数据参数巡礼）

```bash
ask do "先查一次网络档位，然后尝试把网络切到 4g 档（这台模拟器可能不支持，返回失败就原样记录），再查一次档位并切回 off；进热榜用 UI 模式提取条目（字段里要有一个按节点序号取的、一个按文本取的）存为 m4_hot，再用截图 AI 模式提取一次页面主题和可见条目数（不用落库）；对 m4_hot 做三种查询：按标题排序取前3、按条件过滤一次；把巡检标记存进 m4_meta，再从 m4_hot 挑前3条按标题主键 upsert 进 m4_digest；顺路逛一下沸点和课程（用前端筛选）、「我」页面，最后回首页做崩溃检查。"
```

## NLP-5 复杂（对应 C3-全命令全参数巡检）

```bash
ask do "做一次掘金全站巡检：首页顶部分类依次逛关注/推荐/热榜/头条精选/后端/前端；热榜点开第一篇滚动一屏、长按「关注」按钮0.6秒观察反应、落盘一次 UI 树后返回；发现里依次看文章榜、作者榜、专栏；课程里分别用前端和 Android 筛选；沸点进第一个圈子；我页面看阅读记录并读一条标题；回首页后搜一下 rust 看看结果再返回；然后强制停止掘金、用 screen 读出前台包名并报告（强停后前台离开掘金属预期，此时不要做崩溃检查）、重新启动掘金回到首页；最后提取当前页面概况存为 c3_summary，并确认首页搜索框可见。"
```

## NLP-6 复杂（对应 C4-collection采集与数据流水线）

```bash
ask do "在掘金热榜做滚动采集：用边滚边抽模式、按标题主键去重、最多采15条（每屏采不到就用逐条文本方式补），存为 c4_hot_all；点开热榜第一篇读标题截图后返回；把 c4_hot_all 按标题倒序取前5条 upsert 进 c4_digest，再按其中一个真实标题精确过滤复查一次，往 c4_meta 记一条完成标记；回首页搜 Android 把结果提取存为 c4_search；然后强停掘金、确认进程退出、重新启动回首页；最后试一次取 provider=juejin/key=phone 的凭据和一次含「验证码」的短信读取（预期都拿不到，确认App正常即可），并断言各数据集条数达标。"
```

## NLP-7 只读问答（ask，不产生点击——感知参数）

```bash
ask ask "只看当前屏幕回答：现在前台是哪个应用？屏幕分辨率是多少？如果这是掘金首页，顶部分类条里有哪几个分类？用可点元素过滤估算一下当前页大约有多少个可点控件？"
```

## 使用说明

- `ask do "<任务>"`：agent 自主决策（可点击、可滚屏、可落库），对应 YAML 的 `ai:` 步骤合集。
- `ask ask "<问题>"`：只读问答，不产生点击，对应感知参数 smoke。
- YAML 侧的引擎直执行参数（aiTap/aiInput/aiScroll 的显式参数形态）在 NL 形态下由 agent 自行选择等价工具完成，两种形态验证的是同一功能面。
