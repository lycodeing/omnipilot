# 自然语言格式用例（供 `ask do "<任务>"` / `ask ask "<问题>"` 直接执行）

> 与 YAML 用例一一对应：同一套验证点，两种形态。do 任务由 agent 自主决策完成；
> ask 为只读问答（不点击）。分级同 YAML：简单 3-5 页、中等 5-10 页、复杂 10-20 页。

## NL-1 简单（对应 S1-热榜速览与数据提取）

```bash
ask do "打开稀土掘金，看看现在的热榜前几名都是什么，把标题和热度提取存到数据集 hotlist 里，告诉我前3名，然后回到推荐信息流。"
```

## NL-2 简单（对应 S2-我的页面与阅读记录）

```bash
ask do "去稀土掘金的「我」页面读一下当前登录用户名，再打开「阅读记录」看看最近浏览过什么，看完回到首页，确认首页搜索框可见。"
```

## NL-3 中等（对应 M1-搜索全流程与发现页）

```bash
ask do "在掘金里搜索「Android」，把搜索结果前几条的标题和作者提取出来存成数据集 search_android，然后点开第一篇文章滚动读一读，返回后去「发现」的文章榜看看前3名是谁。"
```

## NL-4 中等（对应 M2-多Tab巡检与网络档位探测）

```bash
ask do "把掘金的「沸点」「课程」「我」三个Tab各逛一遍：沸点里进第一个圈子看看再返回；课程里用「前端」分类筛一下小册再换「人工智能」；「我」页面找到每日签到区域看一眼（不要实际签到）；开始前和结束后各查一次网络档位 net_status，全程不要让掘金崩溃。"
```

## NL-5 复杂（对应 C1-全站大巡检）

```bash
ask do "做一次掘金全站大巡检：首页顶部分类条依次逛「关注/推荐/热榜/头条精选/后端/前端」；热榜点开第一条文章滚动阅读两屏并截图；「发现」里依次看文章榜、作者榜、专栏；「课程」里分别用前端和Android分类筛选；「沸点」进第一个圈子；「我」里看阅读记录；最后回首页做崩溃检查，按顺序列出你总共访问过的页面（要求不少于12个页面）。"
```

## NL-6 复杂（对应 C2-搜索采集与数据流水线）

```bash
ask do "在掘金里做一轮数据采集：搜索「Android」提取结果标题与作者存为数据集 search_android；返回再搜索「前端挖掘机」记录结果（可能为空）；去热榜用边滚边抽模式（主键 title，最多滚5屏）采集存为 hot_all；点开热榜第一篇读一下标题；把 hot_all 按标题排序取前5条 upsert 成数据集 juejin_digest；然后强制停止掘金再重新启动，确认能恢复到首页；最后试着取一次 provider=juejin/key=phone 的凭据和一次短信读取（预期都拿不到，确认App不崩溃即可）。"
```

## NL-7 只读问答（ask，不产生点击）

```bash
ask ask "现在屏幕上是什么页面？如果是掘金首页，顶部分类条里有哪些分类？热榜第一名是什么标题、热度多少？"
```

## NL-8 只读问答（ask，查数据集）

```bash
ask ask "数据集 hotlist 和 hot_all 里分别有什么？各有多少条记录？"
```

## 步骤命令（Midscene 命名）

**旧名（do/ask/assert）已废弃**——用旧名会解析报错并提示新名：`do:` → `ai:`，`ask:` → `aiQuery:`，`assert:` → `aiAssert:`。

| 命令 | 说明 |
|---|---|
| `ai:` / `aiAct:` | agent 自主任务 |
| `aiAssert:` | 断言（模型判定） |
| `aiQuery:` + `name:` | 查询/提取（带 name 落库） |
| `aiWaitFor:` + `timeout:` | 等画面稳定（+可选条件判定） |
| `aiTap:` / `aiInput:`+`value:` / `aiLongPress:` / `aiKeyboardPress:`+`keyName:` / `aiScroll:` | **引擎直执行**（直接调工具，不经 agent 选工具） |
| `launch:` / `terminate:` | 启动/强停 App |
| `net:` / `sleep:` | 网络档位 / 等待秒数 |

示例：

```yaml
steps:
  - launch: com.daimajia.gold
  - aiWaitFor: 首页加载完成
    timeout: 8000
  - aiTap: 热榜                    # 引擎直执行
  - aiScroll: down
    distancePct: 75                # 0.75 屏
  - aiAssert: 能看到热榜列表        # 模型判定
  - ai: 顺便看看有没有广告位        # agent 自主
```
